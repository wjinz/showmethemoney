# [Plan] 부부 다이어리(Couple Diary) 탭 신설 및 프로토타입 검증 계획

일자: 2026-04-24 19:20
상태: [DRAFT]

## 1. 목표 (Goal)

부부가 하루의 일과를 감성적으로 공유하고, 대화를 나누며 자연스럽게 지출 총액을 기록하는 **'부부 다이어리'** 탭을 신설합니다. 지출 내역의 세부 사항(프라이버시)은 보호하되, 오늘 우리 가족이 쓴 **'총액'**은 투명하게 공유하여 소통의 창구를 마련합니다.

## 2. 요구사항 및 주요 기능

- **다이어리 타임라인**: 날짜별로 부부의 하루 일과를 카드 형태로 표시.
- **감성적 입력**: 오늘의 기분(Emoji)과 한 줄 일기를 입력하는 기능.
- **지출 요약 공유**: 개별 내역은 숨기고, 사용자가 직접 입력하거나 자동 합산된 '오늘의 총 지출액'만 파트너와 공유.
- **메인 탭 전환**: 기존 '공동(Home)' 탭을 제거하고 '다이어리'를 앱의 엔트리 포인트(첫 화면)로 설정.
- **대시보드 통합**: 기존 공동 탭의 핵심 기능(예산 링, 페이스 예측 등)을 '대시보드' 탭의 위젯으로 통합하여 관리.
- **독립형 프로토타입**: 실제 앱 통합 전, `diary_prototype.html`을 통해 UI/UX를 우선 검증.

## 3. 기술적 설계

### 3.1 데이터 모델 (DiaryItem)

`src/constants/index.js`에 정의될 새로운 데이터 규격입니다.

```javascript
/**
 * @typedef {Object} DiaryItem
 * @property {number} id - 고유 ID (Timestamp)
 * @property {string} date - 날짜 (YYYY-MM-DD)
 * @property {string} who - 작성자 (husband | wife)
 * @property {string} emoji - 오늘의 기분 이모지
 * @property {string} content - 다이어리 내용
 * @property {number} totalSpent - 오늘 지출한 총액 (개인 지출 포함 합계)
 * @property {boolean} shared - 파트너와 공유 여부 (기본 true)
 */
```

### 3.2 상태 관리 및 동기화

- **App.jsx**: `diaries` 상태 변수 추가 및 Supabase `household_data` (Key: 'diaries') 연동.
- **BudgetContext**: `diaries`, `setDiaries`를 전역 컨텍스트에 공급.
- **라우팅**: 기본 경로(`/`) 진입 시 `HomeView` 대신 `DiaryView`가 렌더링되도록 수정.

### 3.3 UI 컴포넌트 구조

- **DiaryView.jsx (New)**: 메인 타임라인 화면. 부부의 대화가 중심이 되는 '스토리' 레이아웃.
- **DashboardView.jsx**: 기존 `HomeView` 위젯(HomeHero, BudgetRing 등)을 수용할 수 있도록 위젯 엔진 확장.
- **Nav.jsx**: `home` 아이콘을 `diary` 아이콘(`BookHeart` 또는 `MessageCircle`)으로 교체.
