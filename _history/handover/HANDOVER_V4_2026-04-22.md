## 2. 구현된 화면 & 컴포넌트

`showmethemoney.html`은 CDN 호스팅된 React 18 + Babel 기반의 **단일 HTML 파일 앱**입니다.
빌드 과정 없이 브라우저에서 직접 실행됩니다.

### 2-1. 디자인 토큰

```css
--bg: #F4F6F8
--surface: #FFFFFF
--primary: #1C2B4A      /* 나 (Deep Navy) */

--text: #111827
--muted: #6B7280
--border: #E5E7EB
--danger: #E8715A
--radius-lg: 24px
--radius-xl: 32px
--shadow: 0 1px 3px rgba(0,0,0,.07), 0 4px 12px rgba(0,0,0,.05)
```

### 2-2. 구현 화면 목록

| 화면 ID | 컴포넌트 | 주요 기능 |
|---|---|---|
| `home` | `HomeView` | 예산 링 차트(`BudgetRing`), 오늘 지출 카드, AI 소비 코치 배너, SOS 대기 배너, 용돈 현황(`AllowanceCard`), 미니 캘린더(`MiniCalendar`), 최근 내역 |
| `history` | `HistoryView` | 4월 지출 합계, 필터 탭(전체/나/지연/총액/건별), `TxRow` 목록 |
| `private` | `PrivateView` | PIN 4자리 잠금(기본값 `1234`), 잠금 해제 시 개인 지출 카드 노출 |
| `sos` | `SOSView` | 채팅 UI, 결재 요청 카드, 승인 버튼, 금액 빠른 입력 칩 |
| `settlement` | `SettlementView` | 카드 결제 현황, 예상 vs 실제 비교, 현금 잔고 계산기 |
| `settings` | `SettingsView` | 부부 용돈 설정, 고정비 관리, 카드 관리, 전체 플랜 요약, 알림 토글, PIN 변경 |

### 2-3. 공통 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| `BottomNav` | 홈/내역/FAB(+)/프라이빗/정산 탭 |
| `BudgetRing` | SVG 도넛 링 — 색상이 사용량에 따라 green→amber→red로 전환 |

| `InputSheet` | 하단 슬라이드업 시트 — 오늘 총액 / 건별 입력 탭 분리 |
| `AllowancePage` | 용돈 설정 서브 페이지 |
| `FixedCostsPage` | 고정비 관리 서브 페이지 |
| `CardManagementPage` | 카드 관리 서브 페이지 |
| `PlanSummaryPage` | 전체 플랜 요약 서브 페이지 |

## 5. Mock 데이터 현황

현재 앱은 **완전 정적 Mock 데이터** 기반으로 동작합니다. Supabase 연동은 이번 작업 범위 밖입니다.

```js
MOCK = {
  budget: 2000000, spent: 847500,
  me: { name: '나', color: '#1C2B4A' },
  partner: { name: '지연', color: '#7A9E87' },
  todayMe: 35000, todayPartner: 28000,
  transactions: [...],   // 7건
  sosMessages: [...],    // 3건
  settlement: { cardTotal:623000, cardEstimate:820000, ... }
}
```
