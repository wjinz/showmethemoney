## 구현 내용 (P0~P6 완료)

### P0 — 전역 상수·헬퍼 (완료)
- `LS` 네임스페이스: `smtm_*` prefix 13개 키
- `CATS`: 9개 카테고리 배열
- `ls`, `lsSet`, `lsGet`, `lsSave`, `fmt`, `toDateKey`, `displayDate`, `getCurrentMonthTx`, `genId`, `generateInviteCode`, `loadOrGenInviteCode`
- `BudgetCtx` / `useBudget` hook

### P1 — App 전면 재작성 + Supabase (완료)
- `db` 객체: `loadAll`, `loadTx`, `saveTx`, `save`, `subscribe`, `unsubscribe`, `loadPendingSos`
- `offlineQueue`: `enqueue`, `flush` (online 이벤트 감지)
- Supabase CDN 스크립트 추가 (`supabase-url` / `supabase-key` meta 태그로 주입)
- App: 전체 상태 (`tx`, `fixed`, `cards`, `budget`, `names`, `allowance`, `notes`, `sosRequests`, `pin`) + Realtime 구독 + 채널 누수 방지(`db.unsubscribe`)
- `BudgetCtx.Provider`로 모든 뷰에 상태 공급

### P2 — OnboardingView + InputSheet 저장 + TxRow 삭제 (완료)
- `OnboardingView`: welcome → create / join 3단계, 이름 설정, 역할 선택, 초대 코드 표시
- `InputSheet`: `onSave` 연결, 날짜 피커, who 역할 토글, 세부내역 저장
- `TxRow`: 우클릭/롱프레스 → 삭제 버튼, `onDelete` prop, `displayDate()` 포맷

### P3 — 뷰 전체 동적화 (완료)
- `HomeView`: `useBudget()`, AI Nudge `/api/nudge` 연동, 예산 링 동적
- `HistoryView`: 월별 이동, 동적 필터(이름 기반), `deleteTransaction` 연결
- `PrivateView`: PIN `useBudget()`, 실제 `is_private` tx 목록
- `MiniCalendar`: 동적 월 이동, 실제 tx 도트, 메모 추가/완료 체크
- `AllowanceCard`: `useBudget()` allowance + 실제 소비액 계산

### P4 — 설정 영속화 (완료)
- `SettingsView`: 초대 코드 표시, 예산 편집, PIN 변경 저장 (`LS.PIN`)
- `FixedCostsPage`: `useBudget().setFixed`, 추가/삭제 → DB 자동 저장
- `CardManagementPage`: `useBudget().setCards`, 추가/삭제 → DB 자동 저장
- `AllowancePage`: `useBudget().setAllowance`, blur 시 자동 저장
- `PlanSummaryPage`: `useBudget()` 데이터 동적 표시

### P5 — SOS / Settlement MOCK 제거 (완료)
- `SOSView`: 빈 배열 초기화, Supabase Broadcast 실시간 채팅, 승인 시 DB 업데이트
- `SettlementView`: `fixed`에서 현금 고정비 자동 계산, 카드별 청구액 입력
