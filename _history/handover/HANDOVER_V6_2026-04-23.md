### 프로덕션 반영 명령 (터미널)

```bash
cd "/Users/dongpayuk/wjin_forwork/어플개발_우진지연 budget"
rm -f .git/index.lock
git fetch origin
git checkout main
git pull --ff-only origin main
git merge --ff-only refactor/vite-return-smtm
git push origin main
```

- `--ff-only`로 머지 커밋 없이 진행
- push 직후 Vercel이 main 빌드 트리거, 1~3분 내 https://showmethemoney-eta.vercel.app 반영
- 충돌 시 main에 다른 커밋이 섞인 상황이므로 rebase 또는 머지 전략 재선택

### Vercel 설정 체크
- Settings → Git → Production Branch = main
- Settings → Domains → showmethemoney-eta.vercel.app 이 Production 라벨
- Build & Development → framework: Vite, buildCommand: npm run build, outputDirectory: dist
