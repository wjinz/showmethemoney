## 3. Antigravity 결정 반영 최종 작업 방향

### 3.1 확정 규칙

1. **옵션 B — Vite 복귀**. `npm run build`로 빌드, Vercel 정상 배포 전환.
2. **디자인 100% 유지**. `showmethemoney.html`의 DOM 구조·인라인 style·색상을 `src/views/*` JSX 내부에 그대로 이식.
3. **Top-Down 이식**. HTML의 View 단위 JSX를 복사 → BudgetContext + API 연동 로직만 주입. `src/`의 기존 View는 참고만.
4. **Gemma4 모델 파이프라인 보존**. `api/ocr.js`, `api/nudge.js`, `api/budget-ai.js`, `api/kids-coach.js` 로직 무수정.
5. **테마 3종 폐기**. `src/styles/globalStyles.js` 내 dark/light/oldschool 분기 삭제. `index.html`의 단일 톤(코랄 포인트 + 오프화이트)만 유지.
6. **smtm_* 네이밍 표준**. src/App.jsx LS 키 전부 리네이밍 + 레거시 키 migration.
