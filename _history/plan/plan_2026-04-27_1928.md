**한계:**

### 사용자 의도 정리

> 카드값이 모두 확정되고 급여도 확정된 상태에서 수기로 계산해보는 탭

입력 필드:
1. **카드 확정금액** — 등록된 카드 모두 노출, 카드별 수기 입력 (이미 구현 ✓)
2. **부부 보유 현금** — 남편 / 아내 각자 입력
3. **부부 월급** — 남편 / 아내 각자 입력 (선택 — 부부 합산 그대로 유지해도 됨, but 분리 권장)
4. **추가 기타 비용** — 항목명/금액 행을 동적 추가/삭제

**계산식:**
```
잔여 = (husbandSalary + wifeSalary + husbandCash + wifeCash)
       - 카드총합
       - 고정현금지출
       - 기타비용총합
```

> "현금"과 "월급"의 분리 의미: 월급은 통장 입금되는 확정 수입, 현금은 손에 쥔 가용 자금(통장 잔액 포함). 사용자 표현을 그대로 따르되, "부부 각자 분리"가 핵심.

// src/views/SettlementView.jsx — 핵심 변경부

export function SettlementView({ onBack }) {
  const { settlements, setSettlements, cards, fixed, tx, install, names } = useBudget();

  const [currentDate, setCurrentDate] = useState(thisMonth);
  const existingData = useMemo(
    () => settlements.find(s => s.date === currentDate),
    [settlements, currentDate]
  );

  // rev.4: 부부 각자 분리 입력
  const [husbandSalary, setHusbandSalary] = useState(0);
  const [wifeSalary, setWifeSalary] = useState(0);
  const [husbandCash, setHusbandCash] = useState(0);
  const [wifeCash, setWifeCash] = useState(0);
  const [fixedCash, setFixedCash] = useState(autoFixedCash);
  const [cardBills, setCardBills] = useState(/** @type {Record<string, number>} */ ({}));
  const [extraCosts, setExtraCosts] = useState(/** @type {ExtraCost[]} */ ([]));

  useEffect(() => {
    if (existingData) {
      // rev.4: 신규 필드 우선, 없으면 rev.3 fallback (currentCash/salary는 husbandSalary로)
      setHusbandSalary(existingData.husbandSalary ?? existingData.salary ?? existingData.currentCash ?? 0);
      setWifeSalary(existingData.wifeSalary ?? 0);
      setHusbandCash(existingData.husbandCash ?? 0);
      setWifeCash(existingData.wifeCash ?? 0);
      setFixedCash(existingData.fixedCash ?? autoFixedCash);
      setExtraCosts(Array.isArray(existingData.extraCosts) ? existingData.extraCosts : []);

      const bMap = /** @type {Record<string, number>} */ ({});
      existingData.cardBills.forEach(b => (bMap[b.cardId] = b.expectedAmount));
      setCardBills(bMap);
      return;
    }
    setHusbandSalary(0); setWifeSalary(0);
    setHusbandCash(0); setWifeCash(0);
    setFixedCash(autoFixedCash);
    setCardBills({});
    setExtraCosts([]);
  }, [existingData, autoFixedCash, currentDate]);

  // 계산
  const totalIncome = (husbandSalary || 0) + (wifeSalary || 0) + (husbandCash || 0) + (wifeCash || 0);
  const totalCardBillsSum = Object.values(cardBills).reduce((s, v) => s + (v || 0), 0);
  const totalExtra = extraCosts.reduce((s, e) => s + (e.amount || 0), 0);
  const calcShortage = totalIncome - (fixedCash || 0) - totalCardBillsSum - totalExtra;
  const isSurplus = calcShortage >= 0;

  const handleSave = () => {
    const billsArr = Object.entries(cardBills).map(([cardId, expectedAmount]) => ({
      cardId, expectedAmount: expectedAmount || 0
    }));
    /** @type {import('../constants/index.js').SettlementItem} */
    const newItem = {
      id: existingData?.id || Date.now() * 1000 + ((Math.random() * 1000) | 0),
      date: currentDate,
      cardBills: billsArr,
      fixedCash: fixedCash || 0,
      // rev.4 신규 필드
      husbandSalary: husbandSalary || 0,
      wifeSalary: wifeSalary || 0,
      husbandCash: husbandCash || 0,
      wifeCash: wifeCash || 0,
      extraCosts,
      // legacy 호환 (currentCash/salary는 합계로)
      currentCash: totalIncome,
      salary: (husbandSalary || 0) + (wifeSalary || 0),
      expectedShortage: calcShortage,
    };
    setSettlements(prev => {
      const filtered = prev.filter(s => s.date !== currentDate);
      return [...filtered, newItem];
    });
    addToast(`${currentDate} 정산 내역이 저장되었습니다.`, "success");
  };

  // ... return JSX (아래 컴포넌트 분리)
}

    setExtraCosts(prev => prev.map(e => e.id === id ? { ...e, ...patch } : e));
  };
  /** @param {string} id */
  const removeRow = (id) => {
    setExtraCosts(prev => prev.filter(e => e.id !== id));
  };

  return (
    <div style={{ background: "white", padding: 20, borderRadius: 24, boxShadow: "0 1px 3px rgba(0,0,0,.07)" }}>
      <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 12 }}>
        <h3 style={{ fontSize: 15, margin: 0, color: "#1C2B4A", fontWeight: 800 }}>추가 기타 비용</h3>
        <button
          onClick={addRow}
          style={{ fontSize: 11, padding: "6px 10px", borderRadius: 99, border: "1px solid #1C2B4A", background: "white", color: "#1C2B4A", fontWeight: 700, cursor: "pointer" }}
        >+ 항목 추가</button>
      </div>

      {extraCosts.length === 0 ? (
        <div style={{ padding: "12px 4px", color: "#9CA3AF", fontSize: 12, textAlign: "center" }}>
          예: 경조사비, 일시 의료비 등 (필요 시 추가)
        </div>
      ) : (
        <div style={{ display: "flex", flexDirection: "column", gap: 8 }}>
          {extraCosts.map(e => (
            <div key={e.id} style={{ display: "grid", gridTemplateColumns: "1.4fr 1fr 28px", gap: 8, alignItems: "center" }}>
              <input
                type="text"
                value={e.label}
                onChange={ev => updateRow(e.id, { label: ev.target.value })}
                placeholder="항목명 (예: 경조사)"
                style={{ padding: "10px 12px", borderRadius: 10, border: "1px solid #E5E7EB", background: "#F9FAFB", color: "#111827", fontSize: 13, fontFamily: "inherit", outline: "none" }}
              />
              <AmountInput value={e.amount} onChange={(v) => updateRow(e.id, { amount: v })} />
              <button
                onClick={() => removeRow(e.id)}
                style={{ width: 28, height: 28, borderRadius: 8, border: "none", background: "#FEE2E2", color: "#E8715A", cursor: "pointer", fontSize: 14, fontWeight: 700 }}
              >×</button>
            </div>
          ))}
        </div>
      )}

      {extraCosts.length > 0 && (
        <div style={{ marginTop: 10, fontSize: 12, color: "#6B7280", textAlign: "right" }}>
          합계 -{total.toLocaleString()}원
        </div>
      )}
    </div>
  );
}

### 마이그레이션 전략

**1단계 — 코드 배포 시점**
- 기존 settlements 데이터는 `husbandSalary`/`wifeSalary`/`husbandCash`/`wifeCash`/`extraCosts` 필드 부재
- useEffect에서 fallback: `husbandSalary = existingData.salary ?? existingData.currentCash ?? 0`, 나머지 신규 필드는 `?? 0` 또는 `?? []`
- 사용자가 다시 저장하면 자동으로 신규 필드로 채워짐

**2단계 — 옵션** (권장하지 않음)
- 일괄 마이그레이션 스크립트는 사용자 의도 추정 위험 → 미실시
- "현금"과 "급여" 슬롯을 부부 사이에 어떻게 분배할지는 사용자만 알기 때문

### 타입 안전성

- `any`/`unknown` 사용 금지 (사용자 지침)
- ExtraCost는 명시적 typedef 추가
- amount는 number, label은 string으로 고정
- 컴포넌트 props는 JSDoc으로 모두 명세

import { describe, it, expect } from 'vitest';

describe('Settlement 재설계 (rev.4)', () => {

    const income = husbandSalary + wifeSalary + husbandCash + wifeCash; // 5,800,000
    const out = fixedCash + cardBills + extra;                          // 3,650,000
    expect(income - out).toBe(2150000);

    expect(total).toBe(0);
  });

    const legacy = { currentCash: 5000000 };
    const husbandSalary = legacy.husbandSalary ?? legacy.salary ?? legacy.currentCash ?? 0;

  });
