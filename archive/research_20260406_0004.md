# 프로젝트 분석 상세 보고서 (Research Report)
**일시**: 2026년 4월 6일 00:04
**시스템 상황**: Gemini 2.5 Flash 마이그레이션 및 무료 티어 최적화 완료

## 1. 개요 (Overview)
본 프로젝트는 **Vite + React** 기반의 지능형 가계부 애플리케이션으로, **Supabase**를 통한 실시간 데이터 동기화와 **Google Gemini AI**를 활용한 예산 추천 및 OCR 기능을 핵심으로 합니다. 특히 2인(남편/와이프) 공유 가계부 시나리오에 최적화되어 있습니다.

---

## 2. 기술 스택 (Tech Stack)
### Frontend
- **Framework**: React 18 (Vite)
- **State Management**: React Context API (`BudgetContext`) + Hooks
- **Visualization**: Recharts (지출 및 예산 시각화)
- **Styling**: Vanilla CSS (Global Styles + CSS Variables)
- **Utility**: `xlsx` (데이터 엑셀 내보내기), `lucide-react` (아이콘)

### Backend & Infrastructure
- **Hosting**: Vercel
- **Database**: Supabase (PostgreSQL + Realtime)
- **Serverless Functions**: Vercel Functions (Node.js)
  - `api/budget-ai.js`: AI 예산 자동 배분
  - `api/ocr.js`: 지수 영수증/카드 내역 인식
- **AI Engine**: Google Gemini 2.5 Flash (v1 API)

---

## 3. 핵심 아키텍처 및 상세 작동 원리

### 3.1 데이터 모델 (Supabase)
데이터는 `household_data` 테이블에 `key-value` 형태로 저장됩니다.
- **구조**: `id` (가계부 고유 ID), `key` (필드명), `value` (JSON 데이터)
- **주요 키**:
  - `tx_YYYY`: 연도별 지출 내역 (Lazy Loading 지원)
  - `fixed`, `install`: 고정비 및 할부 정보
  - `budgets`: 카테고리별 예산 설정
  - `plan`: 급여 및 저축 목표 정보
  - `taxConfig`: 연말정산 최적화 설정

### 3.2 실시간 동기화 (Real-time Sync)
- `src/utils/supabase.js` 내의 `subscribe` 함수를 통해 Postgres 변경 사항을 감시합니다.
- `UPDATE`, `INSERT`, `DELETE` 이벤트를 모두 감지하여 다른 사용자가 입력한 데이터를 즉시 UI에 반영합니다.
- **충돌 방지**: `Date.now() * 1000 + Random` 방식의 ID 생성을 통해 동시 입력 시 데이터 유실을 최소화합니다.

### 3.3 AI 통합 (Gemini 2.5 Flash)
- **무료 티어 최적화**: 최신 표준 모델인 `gemini-2.5-flash`와 Stable `v1` 엔드포인트를 사용하여 할당량 문제 없이 안정적인 호출이 가능합니다.
- **작동 방식**: 프론트엔드에서 이미지를 Base64로 변환하여 Vercel API 서버로 전송 -> 서버에서 API 키를 더해 Gemini 호출 -> 결과를 JSON으로 파싱하여 프론트엔드에 전달.

### 3.4 오프라인 지원 (Local Persistence)
- **Offline Queue**: 네트워크 연결이 끊긴 상태에서 발생한 수정 사항은 `localStorage` 기반의 큐에 저장되었다가, 온라인 복구 시 자동으로 서버로 전송됩니다.
- **Lazy Loading**: 수천 건의 지출 내역을 한꺼번에 로드하지 않고, 사용자가 조회하는 연도의 데이터만 필요할 때 로드하여 성능을 최적화합니다.

## 4. 주요 기능 모듈

1.  **대시보드 (HomeView)**: 현재 예산 사용 현황 요약, 실시간 슬라이더 조절, 요약 차트 제공.
2.  **예산 관리 (BudgetView)**: AI 기반 추천 예산 자동 배분, 고정비/할부 리스트 관리.
3.  **지출 내역 (EntryView)**: 상세 내역 조회 및 수동 입력.
4.  **분석 리포트 (ReportView)**: 카테고리별 통계, 연말정산 최적화 시뮬레이션, 과거 데이터 탐색.
5.  **스마트 스캔 (CardScanSheet)**: 카드 앱 문자 캡처나 영수증 이미지를 AI가 분석하여 자동 입력.
6.  **관리자 모드 (AdminView)**: 시스템 버그 리포트 관리 및 글로벌 설정 제어.

## 5. 향후 개발 제언
- **타입 안정성**: 현재 JavaScript 기반이므로, 점진적으로 TypeScript 인터페이스 정보를 확장하여 런타임 오류를 방지해야 합니다 (이미 `tsconfig.json`은 구성됨).
- **성능 고도화**: 지출 내역이 수만 건 이상 늘어날 것에 대비해 인덱싱은 Supabase에서 처리되지만, 프론트엔드 메모리 관리를 위한 가상 리스트 도입이 필요할 수 있습니다.
- **보안 강화**: `INTERNAL_API_SECRET`을 통한 API 호출 보호가 되어 있으나, 향후 실제 사용자 인증(Auth) 도입을 검토할 수 있습니다.
