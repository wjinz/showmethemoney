## 2. 전체 아키텍처

### 데이터 흐름

```
사용자 액션
    ↓
React 상태 즉시 업데이트 (UI 반응성)
    ↓
Debounce (500ms+)
    ↓
Supabase Upsert (household_data 테이블)
    ↓
Supabase Realtime 브로드캐스트
    ↓
파트너 앱 실시간 수신 → UI 자동 갱신
```

**오프라인 지원**: 네트워크 단절 시 `localStorage` 큐에 변경사항 저장 → 재연결 시 자동 플러시

### 라우팅 구조 (view 상태 기반 조건부 렌더링)

```
App.jsx (view state 관리)
├── home         → HomeView.jsx       (대시보드, 예산 링, 페이스 트래커)
├── entry        → EntryView.jsx      (지출 입력)
├── budget       → BudgetView.jsx     (예산 설정, 고정비, 카드, 시뮬레이터)
├── report       → ReportView.jsx     (월별 리포트, 캘린더, 세금 최적화)
├── settings     → SettingsView.jsx   (앱 설정)
├── admin        → AdminView.jsx      (버그 리포트 관리)
├── dashboard    → DashboardView.jsx  (커스터마이즈 위젯 대시보드)
└── private      → PrivateWalletView  (개인 용돈 관리)
```

## 3. 데이터 모델 (현재)

### Supabase `household_data` 테이블 (Key-Value 방식)

| Key | 타입 | 내용 |
|-----|------|------|
| `tx_YYYY` | Array | 연도별 거래 내역 |
| `budgets` | Object | 카테고리별 예산 배분 |
| `fixed` | Array | 고정비 목록 (날짜, 금액) |
| `install` | Array | 할부 목록 (총액, 개월, 진행률) |
| `cards` | Array | 카드 등록 목록 |
| `plan` | Object | 연간 재무 계획 (급여, 저축목표, 이벤트) |
| `names` | Object | 사용자 표시명 (남편, 아내) |
| `taxConfig` | Object | 연말정산 설정 |
| `assets` | Array | 자산 추적 (개발 중) |

### 거래 데이터 구조

```javascript
{
  id: number,
  date: "YYYY-MM-DD",
  amount: number,
  cat: "food|housing|education|transport|medical|culture|clothing|sub|etc",
  memo: string,
  who: "husband|wife",
  payMethod: "credit|debit|cash",
  type?: "expense|income",
  cardId?: string,
  is_private?: boolean
}
```

## 4. AI/Gemini 통합

### Serverless Functions (Vercel `/api/`)

**① `/api/ocr.js` — 영수증/카드 내역 OCR**
- 모델: `gemini-2.5-flash`
- 입력: Base64 이미지
- 모드: `single` (영수증 1장) / `bulk` (카드앱 스크린샷)
- 출력: `{ amount, cat, memo }` 또는 `[{ date, amount, cat, memo }, ...]`

**② `/api/budget-ai.js` — AI 예산 추천**
- 모델: `gemini-2.5-flash`
- 입력: 총 급여, 고정비, 할부, 저축 목표, 카테고리 소비 이력
- 출력: 최적화된 카테고리별 예산 배분 + 이유 + 팁

**③ `/api/nudge.js` — AI 소비 코치**
- 모델: `gemini-2.5-flash`
- 입력: 지출액, 예산 총액, 거래 요약
- 출력: 40자 개인화 메시지 (톤: "까칠하지만 츤데레")
