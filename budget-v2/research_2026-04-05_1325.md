## 1. 카드 앱 스크린샷 일괄 지출 입력 (Bulk OCR)

### 핵심 메커니즘
기존 단일 영수증 처리 방식을 확장하여, 카드 앱의 이용내역 스크린샷 한 장에서 여러 건의 거래를 동시에 추출하는 파이프라인이 구축되었습니다.

- **서버사이드 (`api/ocr.js`)**: 
  - `mode: "bulk"` 파라미터를 수신하여 프롬프트를 동적으로 변경합니다.
  - `claude-haiku-4-5-20251001` 모델을 사용하여 비용 효율성을 높였습니다.
  - 추출된 데이터를 JSON 배열 형태(`[{date, amount, cat, memo}, ...]`)로 정규화하여 반환합니다.
- **클라이언트 유틸 (`src/utils/ocr.js`)**: 
  - `runBulkOCR(imageFile)` 함수가 추가되어 멀티파트 요청을 처리합니다.
- **사용자 경험 (`src/components/CardScanSheet.jsx`)**:
  - **3단계 프로세스**: 이미지 선택(Idle) → AI 분석(Scanning) → 결과 확인 및 수정(Review).
  - 인식된 항목 중 저장할 항목을 체크박스로 선택할 수 있으며, 날짜/카테고리/메모를 최종 저장 전 수정 가능합니다.
  - 저장 시 `onSave` 콜백을 통해 일괄적으로 데이터베이스(State)에 반영됩니다.

## 2. 카테고리 예산 탭 개선 및 AI 고도화

### 지출 한도 설정 (Utilization Target)
사용자가 전체 예산 가용액 중 실제 배분할 비율을 설정할 수 있는 기능이 추가되었습니다.

- **UI 개선**: 70%~100% 프리셋 버튼과 5% 단위의 정밀 슬라이더(취향에 따른 "직접" 설정)를 제공합니다.
- **AI 연동**: `api/budget-ai.js` 호출 시 `utilizationTarget`을 전달하여, AI가 전체 수입이 아닌 **사용자가 설정한 한도 내에서** 예산을 배분하도록 로직이 수정되었습니다.
- **버퍼 개념 도입**: 100% 미만으로 설정 시, 남은 금액은 "예비비(Buffer)"로 자동 계산되어 표시됩니다.

### 시각적 현황 파악
- **카테고리별 진행 바**: 각 카테고리 카드에 이번 달 실제 지출액과 예산 대비 진행률(%)이 시각화되었습니다.
- **동적 색상 반영**: 
  - 80% 미만: 카테고리 고유 색상
  - 80%~100%: 골드(경고)
  - 100% 초과: 레드(위험) 및 카드 테두리 강조

기존에 수입/저축 탭과 중복되었던 "플랜 요약" 탭이 **읽기 전용 재무 대시보드**로 전면 개편되었습니다.

- **월 현금 흐름 폭포수**: 수입 → 저축 → 고정비 → 변동예산으로 이어지는 흐름을 한눈에 보여줍니다.
- **예산 소진 현황**: 주요 카테고리별 소진 상태와 전체 예산 사용률을 통합 진행 바로 표시합니다.
- **고정비 TOP 3**: 금액이 큰 순서대로 고정 지출을 나열하여 비용 관리 우선순위를 제시합니다.

## 4. 디자인 시스템: Retro Terminal 테마

기존의 Windows 3.1 스타일에서 보다 세련된 **CRT 터미널(Retro Terminal)** 미학으로 테마가 교체되었습니다.

- **색상 팔레트**: 딥 블랙 배경(`#080a06`)에 그린-앰버(`Phosphor Green`) 포인트 컬러를 적용하여 가독성과 감성을 동시에 잡았습니다.
- **타이포그래피**: `Space Mono`(영문/숫자)와 `Noto Sans KR`(한글)의 조와로운 폴백 설정을 통해 터미널 특유의 느낌을 구현했습니다.
- **시각 효과**: 
  - 모든 카드와 버튼의 모서리를 각지게(`border-radius: 2px`) 처리.
  - 화면 전체에 미세한 **Scanline 오버레이**를 추가하여 아날로그 CRT 느낌 전달.
- **인프라 수정**: `UI.jsx`의 `Card` 컴포넌트가 `card` 클래스를 명시적으로 가지도록 수정하여 CSS 선택자 간섭 문제를 해결했습니다.
